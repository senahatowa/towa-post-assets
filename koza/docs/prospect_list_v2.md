## 使い方
1. ★ディレクトリを開く → 個人名の人を選ぶ（法人・大手・スクールブランドは除外）
2. 本人のサイト/Instagram/X を開いて、A/B判定 → 連絡先
3. A/Bの文面（emails_sharp.md）で本人SNS/サイトにアプローチ
4. Codexに「★ディレクトリを巡回して、名前・専門・外部SNS/サイト・A/B をCSV化」と投げれば、収集は自動化できる（DM送信は自動化しない＝BAN回避）
