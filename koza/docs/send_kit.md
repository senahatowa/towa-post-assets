# 送信キット（今日から"送りまくる"用｜コピペで送れる）

## 大前提（ここ重要）
- **DMはLINEに直行**させる（LINEは今すでに生きてる）。だから**LPの公開を待たなくていい**。今日から送れる。
- 送る相手は**個人・小規模だけ**（大手・法人スクール・info@・官公庁は❌）。
- 1アカウント/1媒体あたり**1日15〜20件**まで。まとめて大量送信＝凍結/BAN。分散が命。
- 「停止」「不要」と来たら**全媒体・全アカウントで即除外・二度と送らない**（返信もしない）。
