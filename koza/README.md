## koza-blueprints に載せて公開する（5クリック）
1. github.com/senahatowa/koza-blueprints を開く
2. **Add file → Upload files**
3. この `sites/` フォルダを丸ごとドラッグ（`sites/coach/index.html` … の形のまま）
4. **Commit changes**
5. 数分後、`https://senahatowa.github.io/koza-blueprints/sites/coach/` などで公開される

※ メール／DM の `{LPのURL}` は、公開後のこのURLに差し替える。
